Sobre o Projeto

Protótipo funcional de inteligência artificial capaz de realizar o pré-processamento de fluxos de vídeo e detecção facial em tempo real. O sistema analisa matrizes de imagem frame a frame para isolar áreas de interesse e extrair características estruturais para monitoramento inteligente.

🚀 Minha Contribuição Pessoal (Projeto Autoral)
  • Pipeline de Visão Computacional: Engenharia e construção de todo o fluxo lógico (`src/main.py`), desde a captura bruta da stream de vídeo até a renderização dos filtros aplicados.
  • Implementação de Haar Cascades: Integração e configuração de classificadores baseados em aprendizado de máquina para localização matemática e rastreamento dinâmico de faces.
  • Otimização de Performance: Algoritmos para redimensionamento de resoluções dinâmicas de vídeo, visando a redução do custo de processamento de CPU, além de tratamento de exceções para evitar crashes em frames vazios ou quedas de stream.
  • Manipulação de Matrizes (OpenCV): Desenvolvimento de scripts para conversão de espaços de cores (Gray Scale) e filtragem estrutural avançada (Filtro Canny) para realce de contornos.
